Design system

Page template

Copy this file to start a new page, then delete the sections you don't need. Everything here comes from the shared design files, so it matches the task and changes with it.

Start a new page

Put these three lines in the page's <head>, in this order:

<link rel="stylesheet" href="assets/tokens.css">
<link rel="stylesheet" href="assets/theme.css">
<script src="assets/theme.js"></script>

Then build the body from these parts:

<header class="site-header"><div class="site-header-inner">…</div></header>
<main>
  <header class="page-head"><h1>Title</h1><p class="lead">…</p></header>
  <section class="card"><h2>Section</h2>…</section>
  <div class="actions"><button>Continue</button></div>
</main>
<footer class="site-footer">…</footer>

To change a colour, font or size on every page, edit assets/tokens.json and run npm run tokens. The same file imports into design tools that read W3C design tokens, such as Tokens Studio for Figma or Style Dictionary.
